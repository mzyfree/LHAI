# 裸K LLM V1 冻结发布

发布分支：`codex/naked-k-llm-live-service`。

## 策略口径

- 09:25固定Top3；开盘广度至少37%才允许当日寻找买点，不启用盘中恢复。
- 科创板、创业板权限默认关闭，仅使用现有普通A股交易权限。
- 单票持仓，不加仓；买入当日不可卖，次日起每5分钟判断卖点。
- 卖出后允许寻找另一只股票，同日禁止买回刚卖出的股票。
- 买入证据由代码计数，至少4项；保留原结构、量能、上影线、涨跌停等硬拦截。
- 首根5分钟K线仅跌破VWAP而其他风险事实均不为true时，拒绝仅凭VWAP卖出。
- 模型建议不改变真实仓位，人工成交回填才更新账户。生产默认初始资金5万元。

## 代码与研究边界

实盘入口是`bin/naked_k_llm_live_runner.py`和`service/naked-k-live.ts`，页面为`/naked-k-live`。

`bin/backtest_naked_k_deepseek_portfolio.py`及其依赖保留已有研究选项；冻结回测使用固定Top3、主板、单票全仓、37%门槛、同日买回冷却及首根VWAP保护，不启用动态选股选项。

回测的信号时已完成K线收盘价是成交近似，不保证真实人工执行价格。历史对照中的旧模型决策重放也不代表新模型独立复现或未来收益。

本次发布不包含`research/naked_k_v2/`、动态Top3实验、模型调用日志、账户成交记录、行情文件或本地密钥。环境密钥仍只在本地配置，不提交Git。
